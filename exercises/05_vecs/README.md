# Vecteurs

Les vecteurs (`Vec<T>`) sont l'une des structures de données les plus utilisées en Rust.
Dans d'autres langages, on parlerait simplement de listes ou de tableaux dynamiques
(`list` en Python, `ArrayList` en Java). En Rust, un tableau (`[T; N]`) a une taille
fixe connue à la compilation et est stocké sur la pile, alors qu'un vecteur peut grandir
et est stocké sur le tas.
