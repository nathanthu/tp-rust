# TP : Introduction à Rust 🦀

27 petits exercices pour découvrir les bases de Rust et l'ownership, basés sur [Rustlings](https://github.com/rust-lang/rustlings).

## Installation

1. Installez Rust : <https://www.rust-lang.org/fr/tools/install>
2. Installez Rustlings :

   ```sh
   cargo install rustlings
   ```

3. Clonez ce dépôt, ouvrez un terminal dans le dossier, puis lancez :

   ```sh
   rustlings
   ```

## Contenu

| Dossier | Notions |
|---|---|
| `00_intro` | Fonctionnement de Rustlings, `println!` |
| `01_variables` | `let`, `mut`, inférence de types, masquage (shadowing), `const` |
| `02_fonctions` | Signatures, types, expressions vs instructions |
| `03_conditions` | `if` comme expression, tests |
| `04_quiz` | Récapitulatif des bases |
| `05_vecs` | Vecteurs `Vec<T>` |
| `06_ownership` | Move, `clone`, références `&` et `&mut` |
| `07_strings` | `String` vs `&str` |
| `08_defi` | Défi final sur l'ownership |

Exercices issus de Rustlings (licence MIT), sélectionnés et traduits en français, plus un défi final original.
